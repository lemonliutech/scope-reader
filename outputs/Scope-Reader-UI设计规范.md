# Scope Reader UI 设计规范

> 版本：0.1｜状态：产品与设计评审｜日期：2026-06-18

## 1. 设计目标

Scope Reader 的界面需要同时满足两件事：正文适合长时间阅读，章节结构始终清晰可见。

整体借鉴 Google 搜索结果页（SERP）的信息层级，而非像素复制：正文是稳定的主列，章节树像右侧知识面板一样提供上下文。页面保持开放、轻量、少容器，避免传统后台式卡片堆叠。

设计原则：

1. **正文优先**：阅读内容始终拥有最高视觉权重。
2. **结构常在**：桌面端不隐藏章节树；移动端用抽屉保留快速访问。
3. **状态可解释**：导入、解析、降级和失败都有明确阶段与结果。
4. **控制克制**：非阅读操作在需要时出现，不与正文争夺注意力。
5. **格式无关**：组件使用“图书、章节、位置”等通用语义，不出现 epub.js 专属概念。

## 2. 页面骨架

### 2.1 桌面端（≥ 1024px）

| 区域 | 尺寸与行为 |
| --- | --- |
| 顶栏 | 高 64px，横向内边距 24px，滚动时保持顶部；仅保留品牌、书名、导入与设置 |
| 页面容器 | 最大宽度 1240px，左右自动居中，横向内边距 24px |
| 正文主列 | 宽 720–760px；不使用卡片外框；内容行宽控制在约 65–75 个西文字符 |
| 栏间距 | 64px；窄桌面可降至 40px |
| 章节树 | 宽 300px；`position: sticky`；顶部与顶栏保持 24px 间距 |

正文主列和章节树顶端对齐。章节树高度不超过当前视口可用高度，内部独立滚动；页面滚动仍由正文主列驱动。

### 2.2 平板端（768–1023px）

- 主页面只显示正文，最大宽度 720px。
- 顶栏提供“目录”按钮，点击后从右侧打开宽 360px 抽屉。
- 抽屉打开时保留正文位置；选择章节后自动关闭。

### 2.3 移动端（< 768px）

- 顶栏高 56px，左右内边距 16px。
- 正文单栏，横向内边距 20px；图片不得造成横向滚动。
- 章节树使用全高抽屉，宽度为视口的 88%，最大 360px。
- 底部章节导航改为上下堆叠，触控目标不小于 44×44px。

## 3. 视觉令牌

### 3.1 颜色

首版使用真正的白色背景，不使用偏黄纸张滤镜。颜色关系保持接近 SERP 的高可读性与克制蓝色。

| 令牌 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| `background` | `#FFFFFF` | `#202124` | 页面背景 |
| `surface` | `#F8F9FA` | `#292A2D` | 抽屉、设置、轻量状态区 |
| `text-primary` | `#202124` | `#E8EAED` | 标题与正文 |
| `text-secondary` | `#5F6368` | `#9AA0A6` | 元信息与说明 |
| `border` | `#DADCE0` | `#3C4043` | 分隔线与输入边界 |
| `accent` | `#1A73E8` | `#8AB4F8` | 选中、链接与主要操作 |
| `accent-soft` | `#E8F0FE` | `#303B4E` | 当前章节背景 |
| `danger` | `#B3261E` | `#F2B8B5` | 阻断错误 |
| `warning` | `#B06000` | `#FDD663` | 降级与部分兼容 |

正文链接使用强调色并保留下划线或明显的悬停反馈，不能只依赖颜色表达可点击性。

### 3.2 字体

- UI：`Arial, "Noto Sans SC", system-ui, sans-serif`。
- 默认正文：`Georgia, "Noto Serif SC", serif`；若图书提供合法内嵌字体，优先尊重图书样式。
- 等宽信息：`ui-monospace, SFMono-Regular, Menlo, monospace`，仅用于错误码和技术内容。

| 样式 | 字号／行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 28/36px | 600 |
| 章节标题 | 32/42px | 600 |
| 正文 | 默认 18/32px，可调 16–24px | 400 |
| 小标题 | 20/30px | 600 |
| UI 正文 | 14/22px | 400 |
| 标签／按钮 | 14/20px | 500 |
| 辅助信息 | 12/18px | 400 |

### 3.3 间距、圆角与阴影

- 间距基准：4px；常用值为 8、12、16、24、32、48、64px。
- 按钮与输入圆角：8px；抽屉和弹层圆角：12px。
- 正文与章节树不使用卡片圆角。
- 阴影只用于悬浮设置和抽屉：`0 8px 30px rgba(60, 64, 67, 0.16)`。
- 动画时长 160–220ms；遵守 `prefers-reduced-motion`。

## 4. 关键页面

### 4.1 导入页

首屏只保留品牌、标题、简短说明和一个主要导入区。不得增加数据统计、功能卡片或营销式模块。

内容顺序：

1. `Scope Reader`
2. `打开一本书，保留完整脉络`
3. `文件仅在当前浏览器中处理，不会上传。`
4. 主按钮 `选择 EPUB`
5. 次要提示 `或将文件拖到此处`
6. 格式边界 `支持无 DRM 的 EPUB 2/3 流式图书`

拖拽状态：默认边界为灰色；文件进入时边界变为强调色并显示 `释放以打开图书`；类型不支持时立即显示原因，不进入解析流程。

### 4.2 解析页／解析状态

解析过程不新开复杂页面，而是在导入区域原位切换状态。显示书名或文件名、当前阶段与单一进度指示。

阶段文案固定为：

1. `正在读取文件`
2. `正在检查图书格式`
3. `正在解析图书内容`
4. `正在生成章节目录`
5. `正在准备阅读`

无法计算真实百分比时使用阶段进度，不显示虚假百分比。

### 4.3 阅读页

顶栏左侧为 `Scope Reader`，中部显示截断书名，右侧只保留 `导入新书` 与 `阅读设置`。目录按钮仅在双栏断点以下出现。

正文顶部依次显示章节路径、章节标题和可选元信息。正文内图片最大宽度为 100%，图注使用辅助文字。章节末尾显示上一篇和下一篇；按钮文案带章节名，不只写方向。

右侧章节树顶部显示：

- 书名与作者；
- 总体阅读进度；
- `章节` 标题；
- 多级目录。

当前章节使用浅强调色背景和 3px 左侧标记。父节点只展示展开状态，不与当前节点使用同等强调。

### 4.4 阅读设置

桌面端使用锚定在按钮下方的浮层，移动端使用底部面板。设置项：

- 字号：减小、当前值、增大；
- 行距：紧凑、标准、宽松；
- 主题：浅色、深色、跟随系统；
- 正文边距：窄、标准、宽。

调整后立即作用于正文并自动保存，不增加“确认”按钮。提供 `恢复默认设置`。

### 4.5 错误结果

错误页保持与导入页相同的简单结构，按顺序显示：

1. 人能理解的标题，例如 `这本书使用固定版式`；
2. 一句话解释为什么首版无法打开；
3. 可执行建议；
4. 主要操作 `选择其他文件`；
5. 可折叠的 `查看技术详情`，包含阶段、错误码和原始原因。

局部资源错误不占据整页，在正文对应位置显示紧凑提示，并集中记录在“图书问题”列表中。

## 5. 组件规范

### 5.1 按钮

- 主要按钮：强调色实底，仅用于当前页面的唯一主操作。
- 次要按钮：白底边框，用于导入新书、重试等操作。
- 文字按钮：用于设置、展开详情和低频动作。
- 图标按钮必须有可访问名称与 tooltip；不能只用无语义符号。

状态必须覆盖默认、悬停、按下、键盘聚焦、禁用和加载。焦点环使用 2px 强调色，不依赖浏览器默认样式。

### 5.2 章节树

- 每级缩进 16px，最多视觉展示五级；更深层级保持第五级缩进，避免内容区被挤空。
- 行高至少 36px，触控模式至少 44px。
- 文字最多两行，超出省略；悬停显示完整标题。
- 有子节点的条目使用统一 chevron 图标；展开状态旋转 90°。
- 键盘支持上下移动、左右展开/折叠、Enter 定位。

### 5.3 进度

默认显示百分比与细进度条，不使用环形图或仪表盘。进度是阅读位置估算，界面不宣称精确页码。

### 5.4 Toast 与提示

- 成功保存不显示频繁 Toast；使用安静的状态文本。
- 只为用户需要注意但不阻断的情况显示 Toast，例如进度暂时无法保存。
- 阻断问题必须进入错误结果页，不能只闪现 Toast。

## 6. 交互规则

| 行为 | 结果 |
| --- | --- |
| 点击目录节点 | 跳转并高亮节点；平板／移动端关闭抽屉 |
| 正文位置变化 | 节流保存位置；同步章节高亮和进度 |
| 点击内部链接 | 在当前阅读会话定位 |
| 点击外部链接 | 显示目标域名，确认后新窗口打开 |
| 切换图书 | 先保存当前状态并销毁旧渲染会话 |
| 调整设置 | 立即预览并持久化 |
| 位置恢复失败 | 跳到最近有效章节并明确提示 |
| IndexedDB 不可用 | 允许临时阅读，持续显示“不保存进度”状态 |

## 7. 可访问性

- 正文、章节树、顶栏和设置使用明确的 landmark。
- 所有交互支持键盘；抽屉和弹层需要焦点圈定与关闭后焦点归还。
- 正文与背景、UI 文字与背景满足 WCAG AA 对比度。
- 当前章节不能只靠颜色表示，同时使用左侧标记和 `aria-current="location"`。
- 解析进度使用 `aria-live="polite"`；阻断错误获得程序化焦点。
- 尊重图书语言、文字方向与用户浏览器缩放。

## 8. UI 状态清单

实现与评审必须覆盖：

- 空书库；拖拽进入；文件类型错误；解析五阶段；解析阻断失败；解析成功。
- 正常阅读；章节树折叠；无目录自动生成；图片缺失；外链确认。
- 阅读设置打开；浅色、深色与跟随系统；字号上下限。
- 位置恢复成功；位置降级恢复；存储不可用；存储空间不足。
- 平板目录抽屉；移动端目录抽屉；超长书名；五级以上目录。

## 9. 设计验收

1. 1440px 宽度下，正文、64px 以上栏间距与约 300px 章节树同时成立。
2. 首屏没有多余卡片、徽章、统计和装饰性控件。
3. 正文是最高视觉权重，章节树清晰但不压迫正文。
4. 320px 宽度下无横向溢出，主要触控目标不小于 44px。
5. 所有组件完成键盘、焦点、悬停、禁用、加载和错误状态。
6. 导入、阅读、设置、恢复和异常流程均能从文档中找到对应 UI 规则。
7. UI 文案不暴露 epub.js、CFI、spine 等实现术语；技术详情折叠除外。
8. 深色模式不改变信息层级，也不使用纯黑背景造成过强对比。
