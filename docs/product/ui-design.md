# Scope Reader UI 设计规范

> 版本：0.2｜状态：产品与设计评审｜日期：2026-06-18

## 1. 设计定位

Scope Reader 的最终产物是图书内容网页，不是模拟实体书，也不是带复杂控制台的阅读器应用。

界面严格采用搜索结果页（SERP）的信息骨架：顶部是品牌与搜索框式图书入口，左侧是内容主列，右侧是章节知识面板。知乎答案页只用于参考长文密度、段落节奏与内容型网页的自然滚动，不沿用其社区互动和信息流组件。

核心原则：

1. **网页优先**：内容直接存在于页面文档流中，整页自然滚动。
2. **SERP 骨架**：顶部搜索入口、左侧主结果列、右侧知识面板三部分不可改变。
3. **章节即结果**：当前章节是页面主体，前后章节以相关结果链接形式衔接。
4. **目录即知识面板**：右栏始终解释“这本书是什么、当前在哪里、还能去哪里”。
5. **弱化工具感**：不出现底部阅读控制条、悬浮仪表盘、仿真翻页和密集工具栏。

## 2. 桌面页面骨架

设计基准为 1440px 宽视口。

| 区域 | 规格 |
| --- | --- |
| 顶部主行 | 高 72px；左侧品牌宽约 120px；中部图书入口宽 640–680px；右侧放置低频操作 |
| 顶部次行 | 高 44px；与图书入口左边缘对齐；展示“正文”“图书信息”等少量页面入口 |
| 页面分隔 | 顶部区域底部使用 1px `#DADCE0` 分隔线，不使用阴影 |
| 主体容器 | 最大宽度 1180px；左侧内容 720px；栏间距 64px；右侧面板 320px |
| 内容主列 | 开放白底，无卡片边框和阴影；随页面自然滚动 |
| 章节面板 | `position: sticky`；顶部距视口 24px；最大高度为视口减顶部区域，内部可滚动 |

主体整体偏左，与 SERP 主结果列一致，不采用传统阅读器的水平居中窄纸张布局。

## 3. 顶部 SERP 区域

### 3.1 品牌

左上角显示 `Scope`，不额外出现“Reader”产品副标题。品牌为纯文本或简洁字标，不使用书本插画。

### 3.2 搜索框式图书入口

图书入口外观遵循搜索框：高 46px、圆角 24px、白底、浅灰边界或克制阴影。它不是全文搜索框，首版承担当前图书展示与切换入口。

内容结构：

- 左侧显示当前文件或书名，例如 `人类简史.epub`；
- 无图书时显示 `选择或拖入一本图书`；
- 右侧只保留清除和打开文件两个图标；
- 点击主体区域打开本地图书选择器；
- 拖拽文件进入时整条入口显示强调边界和 `释放以打开`。

不能添加搜索建议、热门图书、账号头像或云端书库入口。

### 3.3 次级导航

首版只提供：

- `正文`：默认选中，显示 3px 蓝色下边线；
- `图书信息`：查看作者、语言、格式与兼容提示；
- `显示设置`：低权重文字按钮，不作为独立主标签。

不使用图标密集的工具导航。

## 4. 左侧章节内容

### 4.1 章节头部

章节头部按 SERP 结果语义排列：

1. 路径：`人类简史 › 第二部分 农业革命`，14px、次级文字色；
2. 章节标题：`第五章 史上最大骗局`，28px/38px、600；
3. 元信息：作者与可选章节进度，13px、次级文字色；
4. 正文：紧随其后，不增加分隔卡片。

章节标题使用正文主色，不强制使用搜索结果蓝色；可导航的章节标题与链接使用强调蓝。

### 4.2 正文排版

- 字体：`Arial, "Noto Sans SC", system-ui, sans-serif`，与 SERP 和知乎内容网页保持一致。
- 默认字号：17px；行高：1.85；段间距：18px。
- 内容行宽：中文约 34–40 字；最大宽度 720px。
- 二级标题：22px/32px、600；三级标题：18px/28px、600。
- 图片最大宽度 100%，与正文左边缘对齐；图注 13px、次级文字色。
- 引用使用 3px 左边线与 16px 左内边距，不包进卡片。
- 代码块使用浅灰表面和横向滚动，仅在图书内容需要时出现。

不使用纸张纹理、仿真页边、衬线书籍主题或翻页动画。

### 4.3 章节衔接

章节末尾以“相关结果”形式显示：

- `上一章：第四章 毁天灭地的人类洪水`
- `下一章：第六章 盖起金字塔`

链接使用 SERP 风格的蓝色标题、章节路径与一行摘要，不使用大尺寸翻页按钮。

## 5. 右侧章节知识面板

面板承担图书上下文，不是应用侧边栏。

顶部内容：

- 书名 `人类简史`；
- 作者 `尤瓦尔·赫拉利`；
- 一行格式信息 `EPUB · 本地文件`；
- 可选的细进度线与 `已读 37%`，不使用仪表盘。

目录内容：

- 标题为 `本书章节`；
- 一级分部与二级章节形成树状结构；
- 当前章节使用浅蓝背景、蓝色文字和 3px 左侧标记；
- 父节点只显示展开状态，不与当前章节同等强调；
- 每级缩进 16px，最多视觉缩进五级；
- 行高至少 36px，标题最多两行；
- 点击章节后更新左侧网页内容并保持页面 URL 可定位。

面板允许一个整体的 1px 边框和 12px 圆角，内部主要靠留白和分隔线组织。不能把每个章节做成卡片。

## 6. 图书信息页

`图书信息` 沿用相同 SERP 骨架，不切换为后台详情页。

左侧按搜索结果区块展示：简介、作者、出版信息、语言与格式兼容性。右侧知识面板保留封面、书名、作者和章节入口。封面是唯一允许的主要视觉图片。

## 7. 导入与异常状态

### 7.1 未导入图书

保留完整顶部骨架。图书入口显示 `选择或拖入一本图书`；主体左列显示简短说明和 `选择 EPUB` 主操作，右侧显示“支持格式”知识面板。

### 7.2 解析中

解析状态出现在图书入口下方与主体左列，不跳转到独立加载页。阶段依次为：读取文件、检查格式、解析内容、生成目录、准备网页。无法获得真实百分比时只显示阶段，不伪造百分比。

### 7.3 阻断错误

左列按 SERP 无结果页组织：明确标题、原因、处理建议、重新选书操作。右侧显示“文件诊断”面板，包含格式、失败阶段和错误码。技术信息默认折叠。

固定版式、关键脚本依赖和 DRM 必须使用不同标题，不能统一显示“打开失败”。

## 8. 视觉令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `background` | `#FFFFFF` | 页面与正文背景 |
| `surface-subtle` | `#F8F9FA` | 代码块、轻提示与空状态 |
| `text-primary` | `#202124` | 标题与正文 |
| `text-secondary` | `#5F6368` | 路径、元信息和说明 |
| `border` | `#DADCE0` | 顶部分隔与知识面板边界 |
| `accent` | `#1A73E8` | 导航、链接与当前章节 |
| `accent-soft` | `#E8F0FE` | 当前章节背景 |
| `danger` | `#B3261E` | 阻断错误 |
| `warning` | `#B06000` | 降级兼容提示 |

间距采用 4px 基准；常用值为 8、12、16、24、32、48、64px。圆角只用于图书入口、知识面板和弹层。正文主列没有容器圆角与阴影。

## 9. 响应式

### 9.1 平板（768–1023px）

- 顶部图书入口缩短，品牌保持可见；
- 主体只显示内容列；
- 章节知识面板由 `本书章节` 按钮打开右侧抽屉；
- 页面仍保持网页自然滚动。

### 9.2 移动端（< 768px）

- 顶部主行分为品牌行和图书入口行；
- 次级导航可横向滚动；
- 正文横向内边距 20px，字号 17px；
- 章节树使用 88vw 的全高抽屉；
- 章节衔接链接纵向排列；
- 不出现固定底部阅读控制条。

## 10. 交互与可访问性

- 页面 URL 应表达当前图书与章节位置，刷新后可恢复。
- 点击章节节点后，页面标题、正文和当前目录状态同步更新。
- 外部链接显示目标域名，确认后新窗口打开。
- 显示设置即时作用于正文，但入口保持低权重。
- 顶部、正文和章节知识面板使用明确 landmark。
- 所有交互支持键盘；当前章节使用 `aria-current="location"`。
- 章节面板抽屉具备焦点圈定，关闭后焦点返回触发按钮。
- 文字与背景满足 WCAG AA；可点击项不能只依赖颜色识别。
- 解析状态使用 `aria-live="polite"`；阻断错误获得程序化焦点。

## 11. 禁止项

- 不设计成带中央书页、左右翻页按钮的传统阅读器。
- 不使用底部进度控制条、悬浮工具球或仪表盘。
- 不使用卡片网格、数据统计、徽章墙和营销 Hero。
- 不加入知乎的关注、赞同、评论、收藏或作者社交模块。
- 不把章节树设计成后台侧边导航。
- 不使用偏黄纸张背景、装饰渐变、玻璃拟态或大面积阴影。
- 不在普通界面暴露 epub.js、CFI、spine 等实现术语。

## 12. 设计验收

1. 1440px 下可明确识别 SERP 的顶部入口、左主列和右知识面板。
2. 页面第一印象是内容网页，不是阅读器应用或后台工具。
3. 左列约 720px，右列约 320px，主体偏左且栏间距不少于 56px。
4. 正文、标题、图片和引用都存在于自然文档流中。
5. 右侧章节树明确表达图书结构和当前位置，但不压过正文。
6. 导入、解析、图书信息和异常状态都保持同一 SERP 骨架。
7. 320px 宽度无横向溢出，主要触控目标不小于 44px。
8. 所有页面均未出现第 11 节所列的阅读器化或社区化元素。
