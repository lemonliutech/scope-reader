# Scope Reader 当前图书组件与图书管理页设计

> 状态：待用户评审  
> 日期：2026-06-18  
> 适用范围：`prototype/` HTML/CSS 交互原型

## 1. 目标

移除阅读页顶部缺乏明确用途的搜索式输入框，改为可识别当前阅读上下文的图书切换组件；新增独立图书管理页，集中管理浏览器中的本地图书。

首版管理能力包括：

- 导入 EPUB；
- 打开或继续阅读；
- 删除图书；
- 显示阅读进度和最近阅读时间；
- 按书名或作者搜索；
- 按格式筛选；
- 按最近阅读时间排序。

本次不实现元数据编辑、批量操作、封面修改、云端同步和账号体系。

## 2. 已确认的视觉方向

### 2.1 顶部当前图书切换器

阅读页顶部保留 `Scope` 品牌，原输入框替换为紧凑的当前图书组件：

- 左侧显示小尺寸封面；
- 中部显示书名；
- 次级信息显示格式和阅读进度，例如 `EPUB · 已读 18%`；
- 右侧使用下拉指示图标；
- 点击后显示最近阅读图书和 `导入图书` 操作；
- 顶部右侧保留独立的 `图书管理` 与 `关于` 入口。

组件宽度由内容约束，不承担搜索功能，不使用搜索图标或快捷键提示。

### 2.2 图书管理页

图书管理页沿用现有 Wiki 风格：白色页面、细分隔线、蓝色链接、紧凑排版，不使用卡片书架和后台仪表盘结构。

页面结构：

1. 顶部沿用 Scope 全局导航；
2. 页面标题为 `图书管理`，显示本地图书数量；
3. 工具区从左到右包含搜索、格式筛选、排序和 `导入图书`；
4. 主体采用紧凑表格；
5. 每行显示图书、格式、进度、最近阅读和操作；
6. 操作包含 `继续阅读` 与 `删除`。

桌面端表格列建议：

| 列 | 内容 | 宽度策略 |
| --- | --- | --- |
| 图书 | 书名、作者 | 弹性主列，不小于 260px |
| 格式 | EPUB | 100px |
| 进度 | 百分比与细进度线 | 110px |
| 最近阅读 | 相对时间 | 120px |
| 操作 | 继续阅读、删除 | 140px |

## 3. 信息架构与路由

原型增加两个页面状态：

- `/`：阅读页；
- `/library`：图书管理页。

首版不引入路由库，使用 `window.history.pushState` 与 `popstate` 管理路径，避免为两个原型页面增加不必要依赖。

导航规则：

- 点击 `图书管理` 进入 `/library`；
- 点击 `继续阅读` 或切换器中的图书进入 `/`；
- 浏览器前进、后退能够恢复对应页面；
- 删除当前图书后停留在 `/library`，不自动打开其他图书。

## 4. 组件划分

### `AppShell`

负责全局顶栏、当前路径和页面切换，不读取具体图书列表结构。

### `CurrentBookSwitcher`

负责显示当前图书、展开最近图书、选择图书和触发导入。组件只通过回调改变当前图书，不直接管理页面路由。

### `ReaderPage`

承载现有正文与章节树。接收当前图书和当前章节，不负责图书增删。

### `LibraryPage`

负责搜索、筛选、排序和表格呈现。具体过滤与排序由纯函数完成，便于单独验证。

### `BookTable`

负责桌面表格和窄屏列表的语义化呈现。删除操作先触发确认弹窗，不直接修改数据。

### `ImportBookControl`

封装隐藏文件输入框与导入结果。首版只接受 `.epub` 文件。

### `ConfirmDialog`

用于删除确认，必须明确显示书名，并提供 `取消` 与 `删除` 两个操作。

## 5. 数据模型与本地状态

原型数据保存在 `localStorage`，键名为 `scope.prototype.library.v1`。文件内容本身不写入 `localStorage`；原型只保存用于界面演示的元数据。

```ts
type LocalBook = {
  id: string;
  title: string;
  author: string;
  format: "EPUB";
  coverUrl: string | null;
  progress: number;
  lastReadAt: string | null;
  importedAt: string;
};
```

状态还包括：

- `currentBookId`：当前阅读图书；
- `query`：搜索文字；
- `formatFilter`：`ALL | EPUB`；
- `sortBy`：`LAST_READ_DESC | IMPORTED_DESC | TITLE_ASC`；
- `pendingDeleteBookId`：等待确认删除的图书。

演示数据首次加载时写入；之后保持用户的导入、进度与删除结果。

## 6. 交互流程

### 6.1 切换图书

1. 点击当前图书组件；
2. 展开最近阅读列表；
3. 选择图书；
4. 更新 `currentBookId` 与该书 `lastReadAt`；
5. 保持或进入阅读页；
6. 关闭下拉层并将焦点返回触发按钮。

### 6.2 导入 EPUB

1. 点击 `导入图书`；
2. 打开系统文件选择器；
3. 校验文件扩展名；
4. 根据文件名生成演示元数据；
5. 将图书加入列表并设置为当前图书；
6. 管理页保持打开，显示新图书。

原型不读取真实 EPUB 元数据，也不保存文件二进制内容。正式产品应由 `PublicationEngine` 与 IndexedDB 接管。

### 6.3 搜索、筛选与排序

- 搜索匹配书名和作者，忽略大小写与首尾空白；
- 格式筛选首版提供 `全部格式` 和 `EPUB`；
- 默认按最近阅读倒序；从未阅读的图书按导入时间倒序排在已阅读图书之后；
- 搜索、筛选和排序组合生效。

### 6.4 删除图书

1. 点击行内 `删除`；
2. 弹窗显示 `删除《书名》？`；
3. 取消时不修改数据；
4. 确认后从列表删除；
5. 如果删除的是当前图书，将 `currentBookId` 设为空；
6. 停留在图书管理页并显示结果。

## 7. 状态与异常

| 状态 | 页面表现 |
| --- | --- |
| 无图书 | 显示简短说明和 `导入第一本图书`，不显示空表头 |
| 无搜索结果 | 保留筛选工具，显示 `没有匹配的图书` 与清除条件操作 |
| 非 EPUB 文件 | 显示 `当前原型仅支持 EPUB`，不加入列表 |
| 重复导入 | 以文件名生成的稳定标识检测；提示图书已存在 |
| 删除当前图书 | 清空当前图书，管理页保持可用 |
| 本地数据损坏 | 放弃损坏数据并恢复演示数据，同时显示一次性提示 |
| `localStorage` 不可用 | 本次会话使用内存状态，刷新后不保留修改 |

## 8. 响应式与可访问性

- `> 860px`：使用完整表格；
- `≤ 860px`：每本图书转换为纵向列表行，标签与值成对显示；
- 当前图书切换器在窄屏只显示封面和书名；
- 下拉层、弹窗支持 Escape 关闭；
- 所有菜单、按钮和表格操作可通过键盘访问；
- 活动页面和当前图书使用 `aria-current`；
- 删除确认后使用可感知的状态文本反馈结果；
- 颜色不作为进度和活动状态的唯一表达方式。

## 9. 验收标准

1. 阅读页不再出现搜索式输入框。
2. 当前图书组件显示封面、书名、格式和进度。
3. 用户能够从切换器选择最近阅读图书。
4. `/library` 能通过顶部入口和浏览器历史访问。
5. 搜索、格式筛选和排序可组合使用。
6. 导入合法 EPUB 后列表新增一行。
7. 非 EPUB 文件不会进入列表，并显示明确原因。
8. 删除操作必须经过确认；删除后本地状态同步更新。
9. 桌面表格保持 Wiki 式紧凑信息密度，窄屏无横向溢出。
10. 阅读页正文与章节树仍保持 `column-gap: 0`，本功能不得破坏现有双栏布局。

## 10. 验证策略

- 构建：`npm run build`；
- 状态：首次加载、持久化恢复、损坏数据恢复；
- 筛选：搜索、格式和排序的单独及组合结果；
- 流程：导入、切换、继续阅读、取消删除、确认删除；
- 路由：直接访问、前进、后退；
- 响应式：桌面和 `≤ 860px`；
- 视觉 QA：顶部组件与管理页对照已确认方案，阅读页双栏重新测量边界。
